# Security

Please do not open a public issue for a security problem in skill-scan itself (for example: a crafted file that crashes the scanner, makes it hang, writes outside the report file, or injects terminal escape sequences into its output).

Report it privately through GitHub: **Security → Report a vulnerability** on this repository.

A pattern that the scanner misses is not a vulnerability: it is a rule request. Open a normal issue with a minimal example (remove any real credential first).
